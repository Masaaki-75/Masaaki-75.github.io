01 / The interface

Many ways to see.
One interface to build on.

Medical images are partial observations of human biology. Histopathology reveals tissue architecture; CT and MRI resolve organ-scale anatomy. Each modality contributes evidence that the others cannot fully provide.

Reusing that evidence begins with its representation. MedVTok maps heterogeneous images and volumes into a common token interface, giving downstream models a shared visual foundation while retaining the structure and meaning each modality carries.

03 / The approach

Preserve the anatomy.
Carry the clinical meaning.

A shared representation has two obligations: retain what was observed, and expose the information that makes it useful across tasks.

Structural fidelity / SliDR

Anatomy continues
between slices.

A volume carries information in how anatomy changes from one slice to the next. Faithful reconstruction must preserve those relationships as well as the individual slices.

Slice Differential Regularization compares how neighboring slices change in the input and reconstruction. Matching these differences preserves the observed anatomical transitions and curvature through depth.

Clinical semantics / MERA

Shared knowledge.
Complementary expertise.

Different modalities reveal different clinical cues. A useful shared representation brings that knowledge together while retaining what each specialist sees best.

Multi-Expert Representation Alignment builds a common representation and also aligns it back to each expert’s own view. This keeps complementary knowledge accessible: what one specialist knows should survive in the shared tokens.

07 / Build with MedVTok

A visual foundation.
Ready to build on.

Medical multimodal systems need visual evidence they can reuse. MedVTok provides a common front end for encoding images and volumes, reconstructing inputs, and adapting downstream models.

Model weights Source code

Start with the same interface

Encode. Reconstruct.
Reuse the tokens.

Get global features, patch tokens, and reconstructions from one model. See the notebook for both 2D and 3D inputs.

Setup & checkpoints 2D & 3D notebook
Python
import torch
from PIL import Image
from models.medvtok import build_model, build_transform

device = "cuda" if torch.cuda.is_available() else "cpu"
model = build_model(
    arch="medvtok-clip-meanpool",
    pretrained_path="weights/ckpt.pth", device=device,
).eval()
transform = build_transform(image_shape=(256, 256))
image = transform(Image.open("data/vis_imgs/sample00.png").convert("RGB"))

with torch.inference_mode():
    outputs = model([image.to(device)], sample_posterior=False,
                    decode=True, return_batched_tensor=False)

features = outputs["feats"]
tokens = outputs["patch_tokens"]
reconstruction = outputs["recons"][0]
